## 🛠️ Tecnologias
- **Front-end:** HTML, CSS e JavaScript Vanilla.
- **Back-end:** Node.js, Express, SQLite3 e Zod.

## ⚙️ Como rodar o projeto

1. **Instale as dependências do Back-end:**
   Navegue até a pasta `backend` pelo terminal e instale os pacotes:
   ```bash
   cd backend
   npm install
   ```

2. **Inicie o servidor (Back-end):**
   Ainda na pasta `backend`, rode o comando:
   ```bash
   npm start
   ```
   *(O servidor rodará em `http://localhost:3000`)*

3. **Abra o Front-end:**
   Abra o arquivo `index.html` (dentro da pasta `frontend`) no seu navegador ou via Live Server no VS Code.

Pronto! O site já estará funcionando e conectado ao banco de dados local.
